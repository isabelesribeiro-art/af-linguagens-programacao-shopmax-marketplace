# ShopMax Marketplace

## Tema do Projeto

ShopMax Marketplace é um marketplace fictício inspirado em grandes plataformas de comércio eletrônico, como Shopee, Mercado Livre e Amazon. O site foi desenvolvido para apresentar produtos de diversas categorias, proporcionando uma experiência moderna, responsiva e intuitiva para os usuários.
